# Dataset

This project uses the **E-Commerce Sales Analytics Dataset** from the Kaggle.

**Source:** https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics

The dataset contains transactional records from a UK-based online retailer between 2021 and 2025.

## Instructions

1. Download the dataset from the official source.
2. Extract the Excel file if it is provided in a ZIP archive.
3. Load the dataset into the analysis notebook using the appropriate file path.

The raw dataset is not stored in this repository. Please obtain it from the official source.

## Data considerations

The analysis examines missing customer IDs, duplicate records, cancellations and returns, positive sales value, and customer purchase behavior.
